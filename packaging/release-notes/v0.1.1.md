Second test build. It fixes what the first real handheld test (MSI Claw 8 EX on Bazzite) turned up in the installer.

**What changed**
- One admin password for the whole install. The installer tells you up front, runs everything in a single prompt, and on KDE turns on Plasma's on-screen keyboard for it (Steam's keyboard can't type into that prompt). A fix that fails no longer stops the install: it is listed at the end with its own Try again, and running the installer again after a half-finished install picks up where it left off.
- ClawDeck users: GameCove now recognises ClawDeck's files on the Claw 8 EX, keeps a backup and adopts them, or says it is already set up by ClawDeck.
- The install command keeps going if you close the terminal.
- Controller navigation in the installer: Easy and Custom are real choices (A picks, the d-pad only moves), every button in a row can be reached, the Device page radios change only on A, the Summary starts at the top, rows that can't be used take no focus, and the Extras page scrolls to everything.
- Install Heroic from the stores step (Flathub, for you only, no password) so Epic, GOG and Amazon sign-in works.
- The "Press A to add it" hint is easy to spot, and the install-stopped page fits the screen.

Install or update (Bazzite or SteamOS, from Desktop Mode):
```
curl -fsSL https://raw.githubusercontent.com/IHulkSmashI/GameCove/main/packaging/get-gamecove.sh | bash
```
