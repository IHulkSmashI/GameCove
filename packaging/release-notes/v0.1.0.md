First test build of GameCove, the all-in-one companion for Linux handhelds.

This is for testers: expect bugs. Back up anything important first.

**Install (Bazzite or SteamOS, from Desktop Mode):**
```
curl -fsSL https://raw.githubusercontent.com/IHulkSmashI/GameCove/main/packaging/get-gamecove.sh | bash
```

What's in it: every store in one library, ROMs from your emulation folders beside your games, Epic and GOG cloud saves with backups, deals and release calendar, every handheld setting (power, fans, screen, audio, controller, RGB, overlay) with per-game and battery/plugged-in profiles, OptiScaler upscaling and frame generation picked for your chip (FSR 4.1.2 on Intel XMX and AMD, XeSS frame generation), a quick menu and on-screen keyboard in games, a device fixes page with undo, firmware/BIOS update checks, and PC streaming with Vibepollo + Moonlight.

Report bugs on GitHub issues or in Discord: https://discord.gg/tuUsn6sSZH
