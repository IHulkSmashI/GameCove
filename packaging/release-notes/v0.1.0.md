First test build of GameCove, the all-in-one companion for Linux handhelds.

This is for testers: expect bugs. Back up anything important first.

**Install (Bazzite or SteamOS, from Desktop Mode):**
```
curl -fsSL https://raw.githubusercontent.com/IHulkSmashI/GameCove/main/packaging/get-gamecove.sh | bash
```

What's in it: every store in one library, deals and release calendar, every handheld setting (power, fans, screen, audio, controller, RGB, overlay, upscaling, frame gen) with per-game and battery/plugged-in profiles, a device fixes page with undo, firmware/BIOS update checks, and PC streaming with Vibepollo + Moonlight.

Report bugs on GitHub issues or in Discord: https://discord.gg/tuUsn6sSZH
