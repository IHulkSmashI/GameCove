# App icons for the showcase screenshots

The Apps view and the Apps shelf in the README screenshots show these desktop apps with their real icons. Each file is the project's own official icon, copied unchanged from its own repository (commit given). They're used only by `tools/showcase/showcase.gd` to render screenshots; none of them is in the app package. Each stays under its project's licence, not GameCove's GPL, and each name and icon belongs to its project. GameCove isn't affiliated with or endorsed by any of them.

On a real handheld GameCove doesn't use these files: it reads each installed app's icon from the system's icon theme.
